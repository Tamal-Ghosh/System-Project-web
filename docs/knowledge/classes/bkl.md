# BKL — Benign keratinocytic lesions

Educational source-based paraphrase. Checked 2026-11-24. Not clinician-validated. General descriptions are not observed patient findings.

## BKL — Overview and label scope
BKL is a grouped benchmark category, not a histological diagnosis. Seborrhoeic keratosis is one common benign skin growth relevant to this group. A BKL output should not automatically be renamed seborrhoeic keratosis.
Reference: https://dermnetnz.org/topics/seborrhoeic-keratosis

## BKL — Presentation and assessment
Seborrhoeic keratoses can have a waxy, warty or stuck-on appearance. Some resemble skin cancers, so uncertain lesions require clinical evaluation. A descriptive feature in this reference is not a feature detected by the classifier. DermNet supports general education, not patient-specific treatment selection.
Reference: https://dermnetnz.org/topics/seborrhoeic-keratosis
